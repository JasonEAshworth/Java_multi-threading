# Java Multi-threading

University coursework: a set of Java labs exploring multithreading and concurrency.

## Layout

- `Lab02/` through `Lab05/`: individual lab assignments

Each lab is self-contained Java source. Compile and run a lab with a standard JDK, for
example:

```bash
cd Lab02 && javac *.java && java Main
```

(Entry-point class names vary per lab.)
